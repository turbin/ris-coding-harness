# 任务：修复重复执行时的状态泄漏

## 背景

当前目录是一个小型 Python 工程（仅标准库），包含：

- `events.py`：一个简单的事件处理模块，内部维护一个处理器注册表，提供 `process(events)` 入口。
- `test_events.py`：已有测试。

## 要求

`events.process(["a", "b"])` 单次调用时结果正确，但该模块被**重复调用**时行为会劣化（重复处理、内部状态持续增长）。请修复，使得：

1. 无论 `process` 被连续调用多少次，对相同输入 `["a", "b"]` 的返回值恒为
   `["logged:a", "audited:a", "logged:b", "audited:b"]`（每个事件被每个处理器恰好处理一次）。
2. 模块内部的注册表大小保持有界，不随调用次数增长。
3. 保持现有公开接口（`process(events)`、各处理器函数）不变；`python3 -m unittest discover` 必须全部通过。
4. 不引入任何第三方依赖。
