# 2026-08-29-min-loop — 最小闭环（Min-Loop）skill

- 来源：用户 2026-08-29 要求——有限 token 预算下，真实工程不需要完整 RSI
  机制（skill 进化/eval/retro），只需要「spec → 验收 → 报告」的自动闭环，
  且以 **skill 作为入口**；代码提交到独立分支
- 目标层：L3（新增 skill + 薄壳脚本，独立分支承载）
- 状态：adopted（分支 `feat/min-loop`）

## 设计

- **入口**：`min-loop` skill（`skills/min-loop/SKILL.md`，随 install.sh
  `skills/*/` 通配自动分发到各 agent skill 目录）
- **机制**：同一 agent 会话内顺序扮演 PM → Coder(TDD RED→GREEN) →
  Reviewer（对抗审阅），MILESTONE ACCEPTED 后报告落 `output/specs/<spec>.md`，
  汇报 DONE / PARTIAL / BLOCKED
- **零机制承诺**：无子代理、无 state/round/verdict、无 eval、无 retro、
  无门禁回写；停机条件最小集（build/test 命令未知、验收不可判定、protected
  触碰时停下询问）
- **与 rsi-loop 的关系**：rsi-loop 一轮子代理工作 ≈ 一次 min-loop；
  min-loop 只交付、不进化
- **批处理**：`run-specs.sh` 薄壳（遍历 `docs/specs/*.md`，headless 逐个
  调用；agent 解析复用 run-loop.sh 约定：`--agent-cmd` / `RSI_AGENT_CMD` /
  `RSI_AGENT_CANDIDATES`）

## 落地文件
